# ukpratik/homebrew-tap

Homebrew casks for [kickFile](https://github.com/ukpratik/kickfile): move files between your phone and laptop over Wi-Fi or a hotspot.

```bash
brew install --cask ukpratik/tap/kickfile
```

Update with `brew upgrade --cask kickfile`; remove with `brew uninstall --cask kickfile` (`--zap` also removes its settings).
